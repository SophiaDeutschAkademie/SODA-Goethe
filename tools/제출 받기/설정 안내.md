# 제출 받기 설정 안내

Modelltest 디지털 시험 화면의 「선생님께 제출하기」를 누르면, 학생의 결과가 선생님 메일로 한 통에 도착합니다. 필기 결과(점수·답안·작성한 글)와, 같은 브라우저에서 한 말하기 실전 연습 기록이 함께 들어 있고, 같은 내용의 txt 파일도 첨부됩니다. Goethe A2·B1·B2와 telc B1·B2·C1 Hochschule가 모두 같은 주소 하나를 씁니다.

Google 계정으로 한 번만 설정하면 됩니다. 아래 순서대로 진행하십시오.

## 1. 스크립트 만들기

1. https://script.google.com 에서 「새 프로젝트」를 엽니다.
2. 기본으로 들어 있는 코드를 모두 지우고, 같은 폴더의 `Code.gs` 내용을 붙여 넣습니다.
3. 맨 위 `TEACHER_EMAIL`에 제출 내용을 받을 메일 주소를 적습니다. 비워 두면 이 프로젝트를 만든 Google 계정의 메일로 옵니다.
4. 제출 기록을 스프레드시트에도 쌓고 싶으면 `SHEET_ID`에 스프레드시트 주소 중간의 ID를 넣습니다. 필요 없으면 비워 둡니다.
5. 저장합니다(Ctrl+S).

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 「배포」 → 「새 배포」를 누릅니다.
2. 톱니바퀴에서 유형을 「웹 앱」으로 고릅니다.
3. 「다음 사용자 인증 정보로 실행」은 「나」, 「액세스 권한이 있는 사용자」는 「모든 사용자」로 고릅니다. 학생은 Google 로그인 없이 제출하므로 「모든 사용자」여야 합니다.
4. 「배포」를 누르고, 권한 승인 창이 뜨면 본인 계정으로 승인합니다. 이 스크립트가 메일을 보내는 권한(메일 전송, 스프레드시트를 쓰면 스프레드시트 권한)을 요청합니다.
5. 배포가 끝나면 나오는 「웹 앱 URL」(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

주소를 브라우저에서 열어 `"ok":true`가 보이면 켜진 것입니다.

## 3. 시험 화면에 주소 넣기

복사한 주소를 Claude에게 알려 주시면 두 저장소(SODA-Goethe, SODA-TELC)에 넣어 올립니다. 직접 하려면 각 저장소 루트에서 다음을 실행합니다.

```
python3 tools/set-submit-url.py "https://script.google.com/macros/s/…/exec"
```

앱의 `digital-src/template.html`과 `digital.html`에 주소가 들어갑니다. 이후 `build-digital.py`로 다시 만들어도 주소는 `template.html`에서 그대로 이어집니다.

## 알아 둘 점

- `Code.gs`를 고친 뒤에는 「배포」 → 「배포 관리」 → 연필 → 「새 버전」으로 다시 배포해야 반영됩니다. 주소는 바뀌지 않습니다.
- Google 무료 계정은 하루에 보낼 수 있는 메일이 100통 안팎으로 제한됩니다. 제출이 하루 100건을 넘으면 Google Workspace 계정(약 1,500통)을 쓰십시오.
- 「소피아 독일어학원 수강생 전용」은 화면의 안내 문구입니다. 주소를 아는 사람은 누구나 보낼 수 있으니, 메일 제목의 학생 이름으로 수강생인지 확인하십시오. 원치 않는 제출이 많아지면 이 스크립트에 수강생 이름 목록 검사를 넣을 수 있습니다.
- 말하기 기록은 학생이 같은 기기·같은 브라우저에서 SODA 말하기 실전 연습으로 연습했을 때만 들어갑니다. 연습 기록이 없으면 필기 결과만 도착합니다.
