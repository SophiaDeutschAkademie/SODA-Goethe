# 작문 연습 데이터 형식 — Goethe-Zertifikat A2 (swN.py)

`sw1.py`(Modelltest I)가 기준 예시입니다. 같은 키, 같은 분량과 어조로 씁니다.

```python
AUFGABEN = [
  {"ko": "과제 요약(합니다체, 두 문장)",                       # Aufgabe 1 · SMS (du)
   "parts": [
     {"fix": "Hallo Carla,"},                                  # 고치지 않는 줄(호칭)
     {"role": "Punkt 1",                                       # Punkt 1–3을 차례대로. 필요하면 "도입", "마무리"
      "a1": "ich habe einen Schlüssel. Er ist nicht von mir.", # 호칭 다음 줄은 소문자로 시작
      "use": "Ich habe … gefunden.",                           # 쓸 A2 표현
      "use_ko": "…을 발견했어요",                              # 표현의 뜻(해요체나 합니다체)
      "tip": "도움말(합니다체). 독일어 조각은 «…»로 감쌉니다.",
      "a2": "ich {habe} einen fremden Schlüssel {gefunden}."}, # {…}는 강조
     {"role": "Punkt 2", …},
     {"role": "Punkt 3", …},
     {"fix": "Liebe Grüße\nJisu"}],                            # 끝인사와 이름
   "sum": ["A1 → A2에서 바뀐 점(합니다체)", …]},              # 세 줄
  {…},                                                          # Aufgabe 2 · E-Mail (Sehr geehrte … → Sie)
]
```

## 짜는 법

- 번호는 Punkt마다 하나씩, 세 개가 기본입니다. 번호 하나에 주어진 표현 하나를 씁니다. 빌드가 Punkt 1–3이 차례대로 다 있는지 확인합니다.
- A1 답안에는 세 가지 내용이 모두 들어 있어야 합니다. 문법은 맞게, 문장은 아주 짧게, 이유는 따로 떨어진 문장으로, 질문은 직접(Wann ist …?), 부탁은 단순하게(Ich will …) 씁니다. 호칭과 끝인사는 A2와 같은 말입니다.
- A2 예시는 A1 문장에 주어진 표현을 넣어 고친 문장입니다. 내용은 A1 답안과 같게 두고, 작은 보충만 합니다. 표현이 들어간 자리를 `{…}`로 감쌉니다.
- 단어 수는 쓰기 가이드와 같이 호칭, 본문, 끝인사, 이름을 모두 셉니다. A2 예시는 과제의 범위(Aufgabe 1은 20–30, Aufgabe 2는 30–40) 안에 들고, A1 답안은 그보다 짧습니다. 빌드가 확인합니다.
- 호칭 뒤 다음 줄은 소문자로 시작합니다(명사와 Sie·Ihr는 대문자). 빌드가 확인합니다.
- 과제의 사실과 어긋나지 않게 쓰고, 해설 페이지의 모범 답안과 같은 문장이 되지 않게 합니다.
- A2 범위 안의 문법만 씁니다: 현재완료(haben/sein), sein·haben·화법조동사의 과거형, 화법조동사(dürfen, sollen 포함), 명령문, 접속법 2식의 정중한 표현(würde, hätte, könnte, wäre), weil·dass·wenn·ob 문장과 간접 의문문, und·aber·denn·deshalb, 비교급, 재귀동사, lassen + 동사원형. 관계문과 um … zu는 쓰지 않습니다.
- 회차마다 표현이 고루 나오게 고릅니다. 같은 표현은 다섯 회차를 합쳐 두 번까지 씁니다.

## 쓰는 말

- 한국어는 **합니다체**입니다. 반말과 ‘~다’ 체는 쓰지 않습니다(빌드가 `ko`, `tip`, `use_ko`, `sum`을 확인합니다). 도움말 안의 뜻풀이는 ‘…의 것이다’처럼 따옴표 안에서만 사전형을 씁니다.
- 문법 용어는 한국어로 쉽게 씁니다: 동사, 주어, 부문장, 간접 의문문, 현재완료, 과거형, 과거분사, 동사원형, 화법조동사, 분리동사, 재귀동사, 접속법 2식, 명령문, 비교급, 3격, 4격. 현재완료의 haben/sein은 ‘조동사’라고 부르지 않습니다(‘sein과 함께 현재완료를 만듭니다’).
- 독일어 조각 뒤의 조사는 한국어로 읽은 소리에 맞춥니다: dass(다스)로, weil(바일)은, wenn(벤)으로, ob(옵)을, kaputt(카푸트)와. 헷갈리면 조사가 독일어에 바로 붙지 않도록 ‘처럼’을 쓰거나, 한국어 낱말 뒤 괄호에 독일어를 넣어 씁니다(예: 호칭(«Hallo Carla,»)과 끝인사).
- ‘von Beruf’ 표현은 쓰지 않습니다.
